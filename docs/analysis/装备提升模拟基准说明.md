# 装备提升模拟基准说明

本文记录装备提升计算器采用的职业套装、技能、消耗品和模拟规则，作为实现维护与回归测试的核对基准。

## 一、统一模拟规则

| 项目             | 规则                                                                       |
| ---------------- | -------------------------------------------------------------------------- |
| 职业方案         | 近战锤、近战盾、近战剑、近战枪、远程弓、远程弩、火法、水法、自然法         |
| 套装来源         | `references/external-tools/mwi-tool/resources` 中对应职业的 `+10` 单刷方案 |
| 装备强化         | 武器、防具统一按 `+10` 计算                                                |
| 技能来源         | 同职业 `+7` 单刷方案中的技能配置                                           |
| 技能等级         | 统一为 `4 / 6 / 6 / 6 / 6`                                                 |
| 项链、耳环、戒指 | 贤者项链、贤者耳环、贤者戒指，统一为 `+5`                                  |
| 背部             | 不装备                                                                     |
| 护符             | 不装备                                                                     |
| Trinket          | 暂不装备；不要与项链、耳环、戒指混淆                                       |
| 袋子             | 暴饮之囊 `+5`                                                              |
| 食物             | 杨桃酸奶 + 杨桃软糖                                                        |
| 模拟方式         | 浏览器本地 Web Worker 执行                                                 |
| 随机数           | 基准装备和对比装备使用相同的 5 组固定随机种子，逐组配对后取平均值          |

### 标准模拟目标

代码中构造专用标准标靶 `/monsters/mst_standard_target`，用于比较持续 DPS。该标靶不会攻击、不会携带技能、不会在模拟中死亡，避免尾刀和重生流程打乱基准装备与对比装备的成对随机序列。

| 属性     |               数值 |
| -------- | -----------------: |
| 生命值   |  1,000,000,000,000 |
| 魔力值   |             80,000 |
| 攻击间隔 | 极大值，等同不攻击 |
| 近战闪避 |                320 |
| 远程闪避 |                320 |
| 魔法闪避 |                320 |
| 护甲     |                 62 |
| 火焰抗性 |                 62 |
| 冰霜抗性 |                 62 |
| 自然抗性 |                 62 |
| 携带技能 |                 无 |
| 掉落表   |                 无 |

每套方案使用 5 个固定随机种子，每个种子模拟 3 小时。DPS 使用实际造成总伤害除以模拟时间。

## 六、咖啡配置规则

表中咖啡是当前代码内置的固定搭配，不在运行时自动枚举最优咖啡。维护这些搭配时按以下规则处理：

1. 先在职业基准套装上离线枚举该职业的有效咖啡组合。
2. 使用相同模拟目标和固定随机种子计算各组合 DPS。
3. 选择平均 DPS 最高的咖啡组合后写入职业预设。
4. 基准装备和对比装备必须使用同一组咖啡，不能各自选择最优咖啡。

这样可以避免装备变化同时引入咖啡变化，保证 DPS 差异只反映装备本身。

## 七、维护检查项

- 装备、技能、咖啡、食物和共用装备 HRID 必须能在当前 `init_client_data` 中找到。
- 技能等级必须保持 `4 / 6 / 6 / 6 / 6`，共用装备强化必须保持 `+5`。
- 标准标靶生命值、闪避、护甲、抗性和空技能列表已由回归测试固定，修改时必须同步测试。
- 调整职业预设、食物、咖啡、固定种子或模拟时长时，应记录九套方案的平均 DPS 变化，并说明变更原因。
