## 当前状态：v2.22.1（2026-11-02，待发布）

本版本修复 MWI 市场伴侣剪贴板导入：恢复原脚本对物品名与数量分行的解析，并让强化物品按对应强化等级加入 MWITools 购物车。用户可见变化见 `docs/changelog.md`。

### MWI 市场伴侣剪贴板导入核对与修复

#### 实现

- 对照参考脚本 `pge.script.user.js` 的 `importClipboardShoppingLists` / `parseClipboard`：原脚本用整段正则匹配，`\s+` 允许物品名与数量跨行；MST 迁移时先按行拆分，导致 `5\nMagic Log`、`Magic Log\n5` 等组合全部丢失。
- 按用户确认，MST 只保留普通文本导入；MWITools 购物车没有导出功能，不迁移参考脚本里读取旧购物清单 JSON 的分支。
- 恢复原脚本的整段匹配语义，数量前置 / 后置、名称与数量同行或分行、空行、CRLF、限量、每小时和补充天数均与原实现一致；限量 / 每小时仍扣减对应强化等级库存。
- 组装 MWITools 购物车条目时补传 `enhancementLevel`，不再把不同强化等级合并到 +0。

#### 验证状态

- `yarn run check` 全绿（381 个测试、dev/prod 打包；prod 头部 `@version 2.22.1`）。
- 新增用例（`tests/core-regression.test.js`「剪贴板解析支持物品名与数量分行」）覆盖数量前置、名称前置、空行、CRLF、限量、每小时及补充天数下的跨行解析。
- 新增用例（`tests/core-regression.test.js`「剪贴板文本导入保留强化等级并扣减对应等级库存」）以跨行输入 `+5\nMagic Log+12` 覆盖完整导入链路，按 +12 的 3 个库存扣减后加入 2 个，并断言 MWITools 购物车参数保留 `enhancementLevel: 12`。
- 另用参考脚本原正则对 40 组同行 / 跨行输入做差异比较，结果无差异。
- 按用户要求，真实页面交互由用户自行验证，本次不记为 Playwright MCP 已验证。

## 后续待办

1. 在真实游戏页面完成主要 UI 手工回归，覆盖工具箱、弹窗、窄屏、语言切换和重复插入。
2. 后续新增功能继续按用户功能聚合，避免重新引入按职责机械细拆的目录。
3. 市场交易记录功能：已按 `docs/analysis/市场交易记录需求说明书.md` 实现并随 v2.19.0 交付；后续游戏更新后需重新核对市场消息字段、状态枚举与标签栏结构（见该文档 §八）。
4. 税费证据的粒度边界（v2.20.0 已按「逐件向上取整的档位判定 + 只有真不符才标注」实现，记录见 `docs/archive/版本验收记录.md` 2.20.0 篇）：① 成交跨税率调整日的记录（实测 2 条）税费混了两个档位，不做判定、退回挂牌价口径；② 完全没有税费证据的记录（`taxTaken` 为 0 的旧数据、购买侧）无法判定差异、也不标星，「金额」列仍是挂牌价口径；③ 落在同一档区间内的价格移动在数据上不可分（4% 档 25 金币宽，如 12 → 20 都在 `(0, 25]`），这类记录按挂牌价口径处理，最多少算一个档位/件。若以后要更准，可考虑：导入时用食用工具的 `taxTaken` 兜底（同源）、或记录浮动标记（`workingPrice > 0`）用于「是否区间价」的展示。
5. 直购 / 直售兜底记录的残留缺口（v2.20.0 已加「未确认」状态，按用户决策不自动删除、不放宽关联）：① 失败请求留下的幽灵记录需要用户自己按状态筛选后删除；② 官方成交价优于委托价时可能同时留下「请求记录 + 官方记录」两条；③ 记录金额是委托价 × 数量（上限口径）。若以后要自动化，可考虑数据修复增加一类「删除过期的未确认兜底记录」（需用户勾选、并提示风险）。
6. 代码清理（2026-10-12 已完成死代码部分；**剩下的渲染期缓存**按用户「清理垃圾代码」的范围未做）：`toolbarTemplate` 每次重绘都会 `estimateStoreBytes`（整仓 JSON 序列化）与「数据修复」区每次重绘都全量扫描（记录量大时是纯渲染开销）——两者都是正确逻辑、不是垃圾代码，加缓存会引入失效风险（记录编辑后 500ms 内 `store.updatedAt` 还没更新），需要时再按「条数 + 各桶最大 updatedAt」的签名缓存。
7. 战斗升级悬浮时间与交战入口（v2.21.0 已发布并实测，记录见 `docs/archive/版本验收记录.md` 2.21.0 篇）：如希望入口常显（而不是悬浮才出现）或调整速率行与四行文案的写法（如 `Lv.135 升级所需时间` 的冒号与空格），说一声即可改。
8. MWI 市场伴侣剪贴板导入（v2.22.1 修复，见本文开头）：由用户在实际游戏页验证普通文本导入，覆盖名称与数量分行、限量 / 每小时、补充天数与强化等级库存扣减。
