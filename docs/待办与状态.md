## 当前状态：2.12.0 地下城收益新增掉落物表格

- 地下城收益结果区新增“掉落物”表格，与“收益结果”表格通过页签切换：掉落物表就是官方宝箱的掉落物列表，普通宝箱与精炼宝箱各一小节（节头注明每日开箱数量），直接列出官方掉落条目；同一物品有多条掉率或数量区间不同的掉落时分别成行（如精华的 100%/400-800 与 5%/2000-4000）。“掉率”列单行展示官方生效掉率，悬浮提示掉落数量区间，掉率是“打开该宝箱”的掉率、不受精炼宝箱稀释。期望数量 = 每日该类宝箱数量 × 掉率 × 平均掉落数量，单元格悬浮提示完整计算公式与结果。宝箱条目按展开内容税前估值（不显示 0）；各节标题行右侧展示该节价值小计，底部合计行只汇总左一/右一总价（小计与合计不含期望数量）。掉落表价格固定按市场报价税前展示，不随“收益扣除市场税”选项变化；掉落表自身不设置纵向滚动条，整体弹窗只保留一个纵向滚动条。
- 2.12.0 内容：`calculator.js` 的 `calculateExpectedChestDrops` 保留递归展开（用于收益估值，`normalDrops`/`refinementDrops`/钥匙统计不变），另新增普通/精良“直接掉落条目期望触发次数”统计（`collectDirectEntries`，条目键 = 物品 + 生效掉率 + 数量区间，只遍历宝箱直接掉落、不递归），`buildDropTable` 按官方直接掉落条目分别成行并标记宝箱来源，宝箱行用新增 `expandChestItems` 递归展开内容按税前单价估值（不显示 0），并输出各节小计（`normal/refinement Ask/BidSubtotal`）；`index.js` 结果区增加“收益结果/掉落物”页签与掉落表渲染（普通/精炼分节），物品列带游戏图标（复用物品精灵图），掉率单行展示并悬浮提示掉落数量区间，期望数量悬浮提示计算公式与结果，各节标题行右侧渲染该节价值小计行，合计行只含左一/右一总价，`formatDropRate` 显示百分数最多两位小数；i18n 新增页签、分节、掉率列头、掉落数量悬浮提示与期望数量公式文案（左一/右一总价与合计复用技能模块既有全局键）；样式新增页签条、掉落表列宽（期望数量列加宽且不换行）、掉率/期望数量悬浮提示与小计行样式，掉落表容器去掉纵向滚动（整体弹窗单一滚动条）。`yarn run check` 通过，新增回归测试覆盖官方直接掉落条目分别成行（pirate_essence 100%/5% 两行、不稀释）、宝箱行按展开内容估值（>0 且 = 数量 × 单价）、普通/精炼分节与各节小计、合计只含左右两列、期望数量公式口径与页签/DOM/样式结构。
