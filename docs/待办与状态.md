- `yarn run check`：执行一次源码修复、测试、dev 打包和 prod 打包，避免重复修复。

## 交付要求

- 用户可见功能变化更新 `docs/usage.md`。
- 长期业务规则变化更新 `docs/业务功能要求.md`。
- 算法、数据来源和限制更新 `docs/analysis/` 下对应文档。
- 清理任务产生的临时文件，不删除历史备份和专项参考资料。
- 每次交付前优先执行 `yarn run check`；无法执行时说明原因。
- 较大改动除自动检查外，必须通过 Playwright MCP 服务打开实际页面完成浏览器验证；极小且低风险的改动可以不验证，但要说明。
- Playwright MCP 只认可 `mcp__playwright__*` 工具；Browser plugin / Browser skill 内置 Playwright、Node REPL 浏览器控制和 `playwright-cli` 均不得替代。
- 验证记录必须区分实际页面与本地预览，并写明 URL/页面类型、视口、关键交互、控制台结果及未覆盖风险。
